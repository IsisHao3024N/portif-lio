# 💻 Portfólio — Izadora

> Meu portfólio pessoal, desenvolvido para apresentar minha trajetória, habilidades, projetos e evolução como desenvolvedora.

## ✨ Sobre o projeto

Este projeto é o meu **portfólio pessoal**, criado com o objetivo de apresentar um pouco da minha trajetória na tecnologia, minhas principais habilidades e projetos desenvolvidos ao longo da minha formação.

Mais do que apenas reunir projetos, o portfólio representa uma parte da minha evolução como desenvolvedora e a busca constante por melhorar minhas habilidades em desenvolvimento web, design e criação de interfaces.

O projeto foi desenvolvido desde a concepção visual até a implementação, utilizando **Figma, HTML, CSS e JavaScript**.

## 🚀 Tecnologias utilizadas

* **HTML5** — estrutura e semântica da aplicação
* **CSS3** — estilização, layout e responsividade
* **JavaScript** — interações e funcionalidades
* **Figma** — prototipação e planejamento da interface
* **Git & GitHub** — versionamento e gerenciamento do projeto

## 🎨 Design

Antes da implementação, a interface foi planejada e prototipada no **Figma**, permitindo definir a estrutura das páginas, organização dos elementos, identidade visual e experiência de navegação.

O desenvolvimento foi realizado buscando criar uma interface:

* Responsiva
* Moderna
* Organizada
* Intuitiva
* Com identidade visual própria

## 📱 Responsividade

O portfólio foi desenvolvido pensando em diferentes tamanhos de tela, adaptando sua estrutura para proporcionar uma boa experiência tanto em **desktop quanto em dispositivos móveis**.

Entre as funcionalidades implementadas está um **menu de navegação específico para dispositivos menores**, controlado através de JavaScript.

Durante o desenvolvimento deste portfólio, pude praticar conceitos importantes de desenvolvimento web, principalmente:

* Estruturação semântica com HTML

* Criação de menu mobile

* Versionamento utilizando Git e GitHub

Além da parte técnica, o projeto também me ajudou a entender melhor a importância de **design, usabilidade, organização de código e experiência do usuário**.
